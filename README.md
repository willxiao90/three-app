# three-app

一个简单的 Three.js 应用，支持车辆按照运动路径巡航和手动控制车辆行驶

[在线预览](https://willxiao90.github.io/three-app/)

## 技术栈

- **React 19** + **TypeScript** — 前端框架
- **Three.js** / **@react-three/fiber** — 3D 渲染
- **@react-three/drei** — 常用 3D 工具组件
- **Vite** — 构建工具

## 功能特性

- 加载工业园区 GLTF 模型
- 车辆按照运动路径巡航
- 手动控制车辆行驶
- 全局视角和车辆视角切换

## 安装与运行

```bash
npm install
npm run dev
```
